# Zepto Sales Dashboard

An interactive sales analytics dashboard built using Apple Numbers, analyzing order-level data from Zepto (quick-commerce). The dashboard provides a consolidated view of sales performance across time, product categories, payment methods, and geography.

## Overview

This project transforms raw transactional data (Order ID, Date, Customer, City, Payment Method, Product, Category, Quantity, Price) into a visual dashboard with key business metrics and trend insights, helping identify what drives revenue and where opportunities lie.

## Key Metrics (KPIs)

- Total Sales
- Total Orders
- Total Customers
- Total Products
- Total Quantity Sold

## Charts

| Chart | Type | Insight |
|---|---|---|
| Sales Trend Over Time | Line chart | Revenue trend by day/week |
| Revenue by Category | Bar chart | Best-performing product categories |
| Payment Method Breakdown | Bar chart | Order share across payment types |
| Revenue by City | Bar chart | Geographic sales distribution |
| Top 10 Products by Revenue | Horizontal bar chart | Best-selling products |

## Tools Used

- **Apple Numbers** — data modeling, pivot tables, chart building, dashboard layout
